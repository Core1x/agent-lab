# Agent Lab · 智能体实验室

本地运行的中文 AI 智能体工作流模拟器。无需依赖安装、API Key 或后端，所有工具和外部动作均采用可复现的教学模拟。

## 打开

直接用现代浏览器打开 `dist/index.html` 即可，这是打包好的单文件网页，可独立复制到其他设备。

建议使用 Chrome 或 Edge 打开。部分应用内预览器不提供完整的文件下载与选择能力，导入、导出和产物下载请在系统浏览器中使用。

开发源文件入口为根目录的 `index.html`，它需要同目录的 CSS、JavaScript 文件。修改源码后运行 `node build.mjs` 更新单文件版。

也可以在本目录启动静态服务器：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8765`。按 Ctrl+C 停止服务器。

## 本版内容

- 8 类工作流：工具循环、串行、路由、并行、计划、评审、主管与子智能体、专家接管。
- 10 个完整场景：研究、写作、客服、并行评审、规划、代码修复、团队研究、专家接管、知识库问答、事件驱动。
- 37 个代表工具，分为 8 类；显示用途和接入方式，支持同用途备用工具。
- Skill、RAG、上下文、记忆、MCP 资源和提示、工具发现、Hooks、协作、人工介入、检查点、输出校验。
- 4 个插件包，支持查看组成、独立停用组件、合并去重。
- 故障注入、失败重试、上下文压缩、检查点恢复、批准／修改／拒绝。
- 暂停、单步、历史回放、A/B 配置对比、JSON 导入导出、记录与产物下载。
- 动画演示剧场：SVG 智能体角色、思考与执行表情、调用／返回光点、并行角色状态和可点击的最近动作；可切换到带流动光点与当前步骤标记的流程全景。
- 进阶自定义工具步骤，可在循环、串行和计划模式中演练任意已启用工具。
- 响应式布局、键盘操作、减少动画偏好、全中文说明及官方参考资料。

## 使用

选择场景，调整工作流、工具和组件，点击开始模拟。点击图节点查看输入、输出与状态。

默认进入动画演示视图。蓝色光点表示发出调用，绿色表示结果返回，橙色表示人工决定。角色表情和工作台随当前步骤变化。暂停会冻结动效；单步和回放展示对应时刻的状态。点击角色查看它已发生的最新动作，点击“刚刚发生”的动作可回看。使用“流程全景”查看完整拓扑；“演示动效”开关和系统减少动画设置均可关闭动态效果。

比较配置时，先保存 A，再修改配置并重新打开对比。同一任务和场景用于两组规则模拟。

自定义工具步骤位于策略页的折叠区。选中工具并添加后，步骤会替换当前场景的工具步骤。最多 8 步；循环模式还受循环上限约束。专用路由、评审与委派模式继续使用专用结构。

工具和组件可独立调整。配置变化会重置当前运行，配置自动保存在本浏览器。无结果、超时或参数异常注入一次，因此成功时只需重试一次。权限错误需调整授权或配置；连接中断只有已启用同用途工具时才自动切换。

人工介入会阻止后续写入。修改说明会进入后续模拟工具参数。从检查点恢复用于演示暂时故障消失后的续跑，不重复已经完成的工具动作。

```powershell
node --test engine.test.js
```

核心验证覆盖 10 个预设、80 种场景与模式组合、缺失工具、故障恢复、并行时序、委派与接管、人工决定、循环上限、插件依赖、回放、导入和全部工具类别。

## 文件

- `data.js`：工具、组件、插件包、场景与资料目录。
- `engine.js`：流程编译、事件生成、状态快照与恢复。
- `app.js`：页面交互、动画、回放和本地存储。
- `theater.js`：角色形象、执行剧场和状态演示。
- `styles.css`：页面视觉、响应式和无障碍动画策略。

## 模拟边界

本版没有真实语言模型或真实 MCP、A2A 连接。自定义任务文字用于上下文和路由匹配，执行遵循所选场景或工具步骤规则。模型档位只影响示例耗时和输入能力，不代表真实产品性能。输出、来源、测试反馈、文件、邮件等均为模拟，下载的产物包含明确的模拟标记。

记忆节点演示读取与写回的含义，使用固定示例记忆；当前真正持久化的是页面配置与 A/B 基线。检查点用于本次运行内的续跑，不是后台持久化任务系统。调度事件只模拟入口，关闭页面不会继续执行。

AG-UI 与 ACP 在概念资料中解释，未实现其协议适配器。来源链接仅在用户点击后打开；应用运行不依赖网络。
